# Rule: Use Context7 MCP Server

Sempre que precisar de documentação de bibliotecas, APIs, referências para geração de código, setups ou demais configurações necessárias, o uso do **MCP server Context7** é obrigatório antes de prosseguir com implementações baseadas em suposições.

## Diretrizes de Uso:
1. Consultar a documentação mais atualizada através do MCP Context7.
2. Ler e aplicar as recomendações oficiais de arquitetura e setup.
3. Não basear soluções complexas apenas em conhecimento pré-existente sem confirmar com a documentação oficial, especialmente quando relacionado a bibliotecas/APIs do ecossistema.
