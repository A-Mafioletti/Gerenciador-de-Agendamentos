# Design System - Gerenciador de Agendamentos

Documentação simplificada das escolhas de interface de usuário (UI) para o projeto.

## Tipografia
* **Fonte Principal:** Inter (via Google Fonts) - Escolhida pela alta legibilidade em telas de todos os tamanhos, ideal para formulários de agendamento.

## Paleta de Cores
* **Cor Primária (Ações e Destaques):** Azul Escuro (`#0f172a` ou similar) - Transmite confiança e profissionalismo.
* **Cor de Fundo (Background):** Cinza muito claro (`#f8fafc`) - Mantém a interface limpa e foca a atenção do usuário no formulário.
* **Cor de Sucesso (Feedback):** Verde (`#10b981`) - Utilizado para a tela de confirmação e tags de status do agendamento.
* **Cor de Texto Base:** Cinza Escuro (`#334155`) - Reduz o contraste extremo do preto puro, tornando a leitura mais confortável.

## Componentes Base
* Os botões e campos de input possuem bordas arredondadas (border-radius) para uma interface mais amigável e moderna.
* O layout é responsivo (Mobile First), garantindo que o cliente final consiga realizar o agendamento perfeitamente pelo celular.
